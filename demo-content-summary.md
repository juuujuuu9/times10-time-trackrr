## How to Access Enhanced Content

**View Task Details:**
```bash
curl -X GET "http://localhost:4321/api/debug-task-content?taskId=35" \
  -H "Cookie: session_token=YOUR_SESSION_TOKEN"
```

**View Team Discussions:**
```bash
curl -X GET "http://localhost:4321/api/collaborations/30/discussions" \
  -H "Cookie: session_token=YOUR_SESSION_TOKEN"
```

**Login and Explore:**
- URL: http://localhost:4321/login
